# Резерв+ (Backup Solution Android)

Профессиональное Android приложение для резервного копирования файлов на WebDAV серверы с поддержкой двусторонней синхронизации.

## 🎯 Возможности

- **Двусторонняя синхронизация** между локальным хранилищем и WebDAV сервером
- **Гибкое расписание**: ежедневно, еженедельно, ежемесячно, по интервалу
- **Умные условия**: синхронизация только при WiFi, зарядке, доступной сети
- **Файловый менеджер** с просмотром изображений и видео
- **История операций** с детальными отчетами и графиками
- **Уведомления** о результатах синхронизации
- **Безопасное хранение** credentials с шифрованием

## 📱 Системные требования

- Android 7.0 (API 24) и выше
- Target SDK: 36
- Kotlin 100%

## 🛠️ Технологический стек

### Core
- **Kotlin** - основной язык разработки
- **Jetpack Compose** + **XML Layouts** - гибридный UI
- **Coroutines + Flow** - асинхронное программирование
- **Hilt** - dependency injection

### Networking
- **OkHttp 5.1.0** - HTTP клиент
- **WebDAV протокол** - синхронизация файлов

### Background
- **WorkManager** - фоновые задачи
- **AlarmManager** - точные будильники

### UI
- **Material 3** - современный дизайн
- **Coil 3.3.0** - загрузка изображений
- **RecyclerView** - списки файлов

### Data
- **DataStore** - настройки приложения
- **Security Crypto** - шифрование credentials

🚀 Использование
1. Настройка подключения
Откройте вкладку "Подключение"
Введите параметры WebDAV сервера:
URL сервера (например: https://cloud.example.com/webdav/)
Имя пользователя
Пароль
Нажмите "Подключиться"
2. Создание задачи синхронизации
Перейдите на вкладку "Задачи"
Нажмите "Создать задачу"
Настройте параметры:
Имя задачи
Тип синхронизации: двусторонняя / в одну сторону
Локальная папка: выберите папку на устройстве
Удаленная папка: путь на WebDAV сервере
Расписание: когда выполнять синхронизацию
Условия: WiFi, зарядка, сеть
Сохраните задачу
3. Запуск синхронизации
Вручную:
В списке задач нажмите на задачу
Нажмите кнопку "Запустить сейчас"
По расписанию:
Включите переключатель "Расписание" в настройках задачи
Приложение автоматически выполнит синхронизацию согласно расписанию
4. Просмотр истории
Откройте вкладку "История"
Просмотрите график успешных/неуспешных синхронизаций
Нажмите на запись для просмотра деталей

🔐 Разрешения
Приложение запрашивает следующие разрешения:
Разрешение
Назначение
INTERNET
Доступ к WebDAV серверу
ACCESS_NETWORK_STATE
Проверка доступности сети
FOREGROUND_SERVICE
Фоновая синхронизация
WAKE_LOCK
Предотвращение сна CPU во время синхронизации
SCHEDULE_EXACT_ALARM
Точные будильники для расписания
POST_NOTIFICATIONS
Уведомления о результатах
RECEIVE_BOOT_COMPLETED
Автозапуск после перезагрузки
READ_MEDIA_*
Доступ к файлам для синхронизации
